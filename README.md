**Taan's Coffee ☕**
Descrição do projeto

Taan's Coffee é um projeto de desenvolvimento web que apresenta uma página dedicada ao universo do café. O site permite aos usuários explorar receitas de café, conhecer diferentes formas de preparo e acessar uma seção para reservar uma mesa.
O objetivo do projeto é criar uma experiência visual agradável, com uma interface organizada e fácil de navegar.

**Tecnologias e técnicas utilizadas**
HTML5: estruturação do conteúdo da página.
CSS3: estilização dos elementos e criação do layout.
Metodologia BEM: organização e nomenclatura das classes CSS.
Flexbox: alinhamento e distribuição dos elementos.
Google Fonts: utilização das fontes Inter e Noto Serif.
Git e GitHub: controle de versão e armazenamento do projeto.

**Funcionalidades**
Apresentação do site Taan's Coffee.
Seção com receitas de café.
Seção para reserva de mesa com formulário.
Navegação entre as seções da página.
Efeitos visuais de interação (hover) nos links e botões.
